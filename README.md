# Nils Frahm — Feutre

A prospect atelier piece for Nils Frahm, composer. Six works suspended as felt-wrapped hammers in a vertical column; strike one and it opens.

**Concept:** *Feutre* (the felt). Nils's signature gesture — placing felt on piano hammers to play without waking the neighbours — is lifted to architecture. The site *is* the moment before a note.

**Three animations, unified under one metaphor:**
- **Immersive reveal** — a loader thread draws the 3.7-metre Klavins Modell 370 across the screen; the wordmark emerges from fog.
- **3D slider** — six hammers placed on a horizontal-axis cylinder; drag/scroll/arrow keys rotate the column, the active one meeting the horizon line.
- **Exploding objects** — a click *strikes* the active hammer; it pulls, slams, and bursts into felt-fibre and ember particles that settle before the detail fold opens.

**Zero borrowed imagery.** Every pixel is drawn from code (SVG + Canvas + CSS 3D).

## Stack
Pure HTML, CSS, vanilla JS. No framework, no dependency.
